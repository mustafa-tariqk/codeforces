# Codeforces Solutions

My competitive programming solutions for [Codeforces](https://codeforces.com).

**Profile:** [mustafa-tariqk](https://codeforces.com/profile/mustafa-tariqk)

## Structure

```
codeforces/
├── Makefile
├── template.cpp
└── <problem>/
    ├── main.cpp
    └── in.txt
```

## Usage

**Create a new problem:**
```bash
make new 4a
```

**Run a solution:**
```bash
make run 4a
```

## My Environment

- macOS (Apple clang 21.0.0)
- `g++` aliased to clang — works fine, just no `bits/stdc++.h`
